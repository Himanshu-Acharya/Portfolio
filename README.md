# Himanshu Acharya — Portfolio

A responsive personal portfolio built with **only HTML5, CSS3 and vanilla JavaScript**.

## Files
- `index.html` — portfolio content and structure
- `style.css` — responsive design, animations and theme
- `script.js` — theme toggle, mobile navigation, reveal animations and back-to-top
- `Himanshu_Acharya_Software_Developer_Resume_Final.pdf` — resume used for the portfolio

## Run
Open `index.html` in a browser. No build step or framework is required.

## Before publishing
Replace the placeholder GitHub and LinkedIn URLs in `index.html` with your actual profile URLs.

## Design references
The structure and interaction ideas were informed by public vanilla HTML/CSS/JS portfolio examples on GitHub, including:
- https://github.com/raina-adi/PORTFOLIO
- https://github.com/codewithsadee/pfolio
- https://github.com/asad-albadi/portfolio
- https://github.com/byte-way/developer-portfolio

The implementation and visual design here are original and tailored to Himanshu's resume.
